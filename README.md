# Benjamin Lerch — personal website

Minimal one-page GitHub Pages website with three sections:

- About
- Research
- Policy

## Publish on GitHub Pages

1. Open your GitHub Pages repository (normally `YOUR-USERNAME.github.io`).
2. Upload the contents of this folder to the **root** of the repository.
3. Make sure `index.html` and `styles.css` are visible directly on the main repository page.
4. Go to **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then save.

## Updating the site

- Text and publication entries: edit `index.html`.
- Fonts, spacing, colors and layout: edit `styles.css`.
- The portrait currently loads from the previous Google Sites page. For a fully independent site, save your portrait as `assets/profile.jpg` and change the image `src` in `index.html` to `assets/profile.jpg`.
